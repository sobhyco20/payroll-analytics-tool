# 📊 تحليل تكاليف الرواتب — العجيمي الصناعية

أداة ويب (HTML/JS فقط، بدون سيرفر) لتحليل تقارير "Employees Detailed Payroll Report" الشهرية:
تكلفة كل **إدارة**، تكلفة كل **موظف**، اتجاه التكلفة عبر الأشهر، ودعم رفع حتى **12 ملف شهري** (سنة كاملة) دفعة واحدة.

## 🔒 خصوصية البيانات

- **كل المعالجة تتم داخل المتصفح فقط** (JavaScript + مكتبة SheetJS) — لا يوجد أي سيرفر خلفي، ولا يتم رفع أي ملف أو بيانات راتب إلى أي جهة خارجية.
- ملفات الإكسل الفعلية **لا تُرفع أبدًا إلى GitHub** (مستثناة عبر `.gitignore`) — المستودع يحتوي فقط على كود الأداة.
- يُنصح مع ذلك بجعل المستودع **Private** على GitHub، كإجراء احترازي إضافي.

## ✨ المزايا

- رفع عدة ملفات شهرية دفعة واحدة (سحب وإفلات أو اختيار من الجهاز).
- التعرف التلقائي على: **الشهر**، **السنة**، و**الجهة/مجموعة الرواتب (Pay Group)** من داخل كل ملف — دون إدخال يدوي.
- إذا رُفعت ملفات لأكثر من جهة/مصنع واحد، تظهر **تبويبات منفصلة لكل جهة** + تبويب **"المجموعة (الكل)"** يجمع النتائج دون خلط بيانات الجهات ببعضها.
- تحقق تلقائي من صحة القراءة: مقارنة الإجمالي المحسوب بصف الإجمالي الموجود داخل الملف نفسه، مع إشارة ✅/⚠️ لكل ملف.
- **تكلفة كل إدارة**: عدد الموظفين، الإجمالي، متوسط التكلفة للموظف، والنسبة من الإجمالي — مع رسم بياني ورقم تصدير Excel.
- **تكلفة كل موظف**: إجمالي التكلفة والخصومات والصافي عبر الأشهر المختارة، مع إمكانية فتح تفاصيل كل شهر لموظف معيّن، بحث، وترتيب حسب أي عمود.
- اختيار المقياس: **إجمالي التكلفة قبل الخصومات** (تكلفة الشركة الفعلية) أو **صافي الرواتب المدفوعة**.
- فلترة الأشهر المعروضة داخل كل جهة (مثال: عرض شهر واحد فقط أو مقارنة عدة أشهر).
- تصدير أي جدول (الإدارات / الموظفين) كملف Excel جاهز.

## 📁 صيغة الملفات المطلوبة

الأداة مصممة خصيصًا لقراءة تقرير **"Employees Detailed Payroll Report"** كما يُصدَّر من النظام دون أي تعديل على رؤوس الأعمدة، وتشمل الأعمدة المتوقعة:

`Personnel number, Name, National/Iqama Id, Department, Working days, Basic Salary, Housing Allowance, Transportation Allow, Own Car Allowance, Fixed Overtime, Overtime, Food Allowance, Incentives, Mobile Allowance, Operator Allowance, Leave, Adjustment Increment, GOSI Allowance, Total Additions, Loans Deductions, Absence Deduction, Food Deduction, Social Insurance, Penalties, Leave Absence, Adjustment Deduction, Total Deductions, Total Salary, Branch, All Overtime`

- عمود **Department** يُقرأ بصيغة `الإدارة|الفئة` (مثال: `Production|Industrial`) ويُقسَّم تلقائيًا.
- الأداة تبحث عن صف العناوين (الذي يبدأ بـ "Personnel number") تلقائيًا، فلا مشكلة إن اختلف عدد صفوف الترويسة قليلًا بين الملفات.
- إن تغيّرت رؤوس الأعمدة أو بنية الملف بشكل كبير، ستظهر رسالة عربية واضحة توضح سبب تعذّر القراءة بدل توقف الصفحة بصمت.

## 🚀 التشغيل

### محليًا (بدون GitHub)
افتح ملف `index.html` مباشرة في المتصفح (Chrome/Edge) — لا حاجة لأي تثبيت.

### الرفع على GitHub واستضافة الأداة عبر GitHub Pages
```bash
# داخل مجلد المشروع
git init                     # (تم تنفيذها مسبقًا في هذه النسخة)
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git branch -M main
git push -u origin main
```
ثم من إعدادات المستودع على GitHub:
`Settings → Pages → Source: Deploy from a branch → Branch: main / (root)` — واحفظ.
بعد دقيقة أو دقيقتين ستصبح الأداة متاحة على رابط من نوع:
`https://USERNAME.github.io/REPO_NAME/`

> ملاحظة: نظرًا لأن المعالجة كاملة داخل المتصفح، تعمل الأداة بنفس الكفاءة سواء فتحتها محليًا أو عبر GitHub Pages — الاستضافة فقط لتسهيل الوصول إليها من أي جهاز دون تحميل الملفات.

## 🛣️ إمكانيات مستقبلية مقترحة

- حفظ "جهات محفوظة" (قائمة مصانع معتمدة) بدل الاعتماد فقط على القيمة المكتشفة تلقائيًا من كل ملف.
- مقارنة بين سنتين (Year-over-Year) لكل إدارة.
- تنبيهات تلقائية عند ارتفاع تكلفة إدارة أو موظف بنسبة غير معتادة بين شهرين متتاليين.
